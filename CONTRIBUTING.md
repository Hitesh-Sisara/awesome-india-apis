## 🚀 How to Add an API (Step-by-Step)

Even if you've never contributed to open source before, you can do this in **5 minutes**!

### Option 1 — Edit Directly on GitHub (Easiest)

1. Go to [README.md](README.md)
2. Click the ✏️ **pencil icon** (top right of the file)
3. Add your API to the correct category table
4. Scroll down → click **"Propose changes"**
5. Click **"Create pull request"**
6. Done! ✅

### Option 2 — Fork & Clone (For Developers)

```bash
# 1. Fork this repo (click Fork button on GitHub)

# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/awesome-india-apis.git
cd awesome-india-apis

# 3. Create a new branch
git checkout -b add/your-api-name

# 4. Make your changes in README.md

# 5. Commit
git add README.md
git commit -m "Add: Your API Name to [Category]"

# 6. Push
git push origin add/your-api-name

# 7. Open a Pull Request on GitHub
```

## 📝 API Entry Format

Add your API in the correct category table using this format:

```markdown
| API Name | Short description of what it does | `Auth Type` | [Docs](https://link-to-docs.com/) |
```

### Auth Types:
- `None` — No authentication needed (free, open)
- `API Key` — Requires an API key (usually free signup)
- `OAuth` — Requires OAuth authentication

### Example:
```markdown
| MyAPI India | Fetch Indian holiday list by year | `None` | [Docs](https://myapi.in/docs) |
```

## ✅ Checklist Before Submitting

Please make sure your API submission meets these criteria:

- [ ] The API is **India-specific** or has significant India-focused features
- [ ] The API link **actually works** (test it!)
- [ ] Description is **short and clear** (under 80 characters)
- [ ] Added to the **correct category**
- [ ] No **duplicate** of an existing entry
- [ ] API is **legal and publicly accessible**

---

## 🆕 Adding a New Category

If your API doesn't fit any existing category:

1. Add a new `##` section in README.md
2. Add the category to the Table of Contents
3. Use the same table format
4. Mention in your PR description why you added a new category

## 🐛 Reporting Issues

Found a broken link? API no longer works?

1. Go to [Issues](https://github.com/pawapawa007/awesome-india-apis/issues)
2. Click **"New Issue"**
3. Choose the **"Broken Link"** template
4. Fill in the details
